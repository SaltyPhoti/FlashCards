Pocket Cards — GitHub Pages 上传说明

1. 先解压 Pocket_Cards_GitHub_Pages.zip。
2. 打开 GitHub 的 pocket-cards 仓库。
3. 选择 Add file → Upload files。
4. 上传解压后文件夹“里面的所有文件”，不要只上传 ZIP，也不要多套一层文件夹。
5. 提交（Commit）这些文件。
6. 打开仓库 Settings → Pages。
7. 在 Build and deployment 中选择 Deploy from a branch。
8. Branch 选择 main，目录选择 /(root)，然后 Save。
9. 等待约 1–3 分钟，GitHub Pages 页面会显示网站地址。

正确的网址通常是：
https://你的GitHub用户名.github.io/pocket-cards/

重要说明：
- 卡片、图片和复习记录只保存在当前浏览器/设备中，不会提交到公开仓库。
- 第一次打开网站后，可在 iPhone Safari 中选择“共享 → 添加到主屏幕”。
- 更换手机或清除 Safari 数据前，请在 Pocket Cards 的“管理”页下载完整备份。
- README_UPLOAD_FIRST.txt 本身上传或不上传都不会影响应用。
